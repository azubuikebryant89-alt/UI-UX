## Long description (draft)

**Portside is a client-operations template for agencies and freelancers** — a polished
marketing site and a working client-portal application UI in one coherent product, not
two disconnected purchases.

Most admin dashboard templates are generic: a sidebar, some charts, and no story. Portside
is built around one real workflow — lead → proposal → project → tasks → files → invoice —
so a prospect looking at your marketing page and a team member using the actual workspace
see the same product.

**What's included:**
- 6 marketing & auth pages (Home, Features, Pricing, Login, Register, 404)
- 10 application screens (Dashboard, Clients, Client Details, Projects, Project Details,
  Tasks, Proposals, Invoices, Files, Settings)
- A full documentation page with a 10-minute customization guide
- One shared design system: CSS custom properties for color, type, spacing and radius —
  recolor the whole product by editing a handful of tokens
- Real interactions, not static mockups: a drag-and-drop task board, sortable/filterable
  tables, modal dialogs, dropdown menus, toast notifications, client-side form validation
- Realistic, honestly-fictional demo data — no Lorem Ipsum, no fake ratings or reviews
- Fully responsive from 320px to 1920px
- Zero dependencies: semantic HTML5, modern CSS, vanilla JavaScript, no build step

**What Portside is not:** a hosted SaaS product. It's a front-end foundation — there's no
backend, database, or authentication included. Every demo interaction is clearly
documented as UI-only, with a guide for wiring it to your own backend.

**Perfect for:** developers building a client-facing tool for an agency, freelancer, or
consultancy — either to launch as a real product or to customize for your own studio.
